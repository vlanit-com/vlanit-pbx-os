# Спека: полная фирменная тема dialog (1.3.3)

## Корень

На скринах мастера 1.3.2 (`build/release-shots/1.3.2/`) списки дисков/сети —
серый внутренний menubox; активные кнопки и выделение — коричневые
(YELLOW как фон VGA). В `installer/dialogrc` не было ключей
`menubox_*`, `form_*`, `searchbox_*`, `position_indicator_*`,
`use_colors`/`use_shadow` — dialog подставлял compiled-in defaults
Debian (светлый menubox, cyan/blue формы). Золото бренда (#D4AA6A)
как фон выделения в 16 цветах читается плохо.

## Решение

Что · значение · файл · проверка:

- Полный `installer/dialogrc` · все ключи темы; `use_colors=ON`,
  `use_shadow=OFF`; фон BLACK; текст WHITE; рамки/заголовки/теги
  YELLOW; выделение и активная кнопка — BLACK на WHITE (#F5F4F0);
  gauge fill — BLACK на YELLOW · `installer/dialogrc` (DIALOGRC из
  `common.sh`) · скриншоты `build/release-shots/1.3.3/` (нет серого
  menubox, нет синих/cyan акцентов Debian).
- Прогон · `scripts/shot-installer-walk.sh` после `make iso` · те же
  имена кадров, что 1.3.2 (02–12) + зеркальный путь.

Отклонено: 256-цветный RGB в dialogrc — на vt/QEMU stdvga нет гарантии;
YELLOW-фон для кнопок — коричневый и низкий контраст на скринах 1.3.2.

## Проверка (as-built 2026-11-18)

```bash
make iso
# ISO из make — root:root 644; QEMU usb-storage открывает RW →
# Permission denied. Обход: chmod 666 копии или ISO=/tmp/….iso
docker run --rm -v "$PWD:/build" -v /tmp:/tmp vlanit-build:1.2 \
  bash -c 'cp -f /build/dist/VLANit-PBX-1.3.3-amd64.iso /tmp/vlanit.iso && chmod 666 /tmp/vlanit.iso'
ISO=/tmp/vlanit.iso bash scripts/shot-installer-walk.sh
```

Факты по `build/release-shots/1.3.3/` vs `1.3.2/03-disk-select`
(downsample 120×68, классификатор пикселей):

| | gray menubox | BROWN (жёлтый фон VGA) |
|---|---|---|
| 1.3.2 | 744 | 31 |
| 1.3.3 | 61 | 0 |

Визуально: золотые рамки/заголовки; списки на чёрном; OK — светлая
плашка. Fill gauge остаётся «коричневым» (YELLOW как фон 16-цветной
VGA) — ограничение палитры, не утечка Debian defaults.
