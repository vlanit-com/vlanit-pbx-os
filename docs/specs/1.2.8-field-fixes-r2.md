# Спека 1.2.8 — полевые фиксы #10/#17/#18 (второй раунд) + безопасность

Источник: полевой тест 1.2.6/1.2.7 (Alexander Kuznetsov, 2026-11-14) —
комментарии к issue #10, #17, #18 и три пункта безопасности (не issue).

## #10. Provisioning MikoPBX: корень — отсутствие /.dockerenv

**Корень (подтверждён полем и исходниками образа):** DockerCloud проверяет
`System::isDocker()` — наличие файла `/.dockerenv` в контейнере. В Podman
файла нет → provisioning НЕ выполняется вообще: env (PBX_NAME, SSH_PORT,
WEB_ADMIN_PASSWORD) в контейнер попадают (`podman exec env` их видит), но
провайдер их не применяет. Поэтому имя АТС стандартное, SSH на 22, пароль
не принимается, флаг atc-password-broken создавался при любом раскладе.
Upstream: https://github.com/mikopbx/Core/issues/1104.

**Решение:** `Volume=/var/lib/vlanit/dockerenv:/.dockerenv:ro` — пустой
файл-заглушка в Golden Image. Проверено полем на 1.2.5: с этой строкой
пароль из мастера принимается, стандартный — нет, имя и порт SSH из
мастера применяются. Теперь DockerCloud применяет env при КАЖДОМ старте
контейнера (12-factor), в т.ч. после reboot → самолечение через REST v3
(п.4 ниже) остаётся как вторая линия защиты.

## #17. ssh.service: порядок ExecStartPre

**Корень:** штатный юнит начинается с `ExecStartPre=/usr/sbin/sshd -t`;
drop-in ДОБАВЛЯЕТ шаг в конец списка → `sshd -t` падает до генерации
ключей (5 неудач, rate limit).

**Решение:** drop-in сначала сбрасывает список (`ExecStartPre=`), затем
`ssh-keygen -A` → `sshd -t`. Дополнительно host keys генерируются ПРИ
УСТАНОВКЕ (deploy.sh, chroot target) — sshd стартует с первой загрузки
вообще без перезапусков; drop-in — подстраховка на случай ручной чистки.

## #18. Часовой пояс АТС ≠ пояс устройства

**Корень:** мастер писал /etc/timezone хоста, но контейнер АТС жил в
Europe/Moscow (образ по умолчанию): `podman exec mikopbx date` — MSK,
PBXTimezone = Europe/Moscow → сдвиг времени в записях звонков.

**Решение:** три слоя — (1) `Volume=/etc/localtime:/etc/localtime:ro`;
(2) `TZ=<пояс>` в VLANIT-ENV блоке quadlet (deploy.sh передаёт TZ из
мастера); (3) heal-служба выравнивает настройку `PBXTimezone` в БД АТС
через REST v3 (`PATCH /pbxcore/api/v3/time-settings`, поле подтверждено
исходниками: PbxSettings::PBX_TIMEZONE).

## Безопасность (фидбек «сюда, а не в Issues»)

1. **localhost bypass API АТС** (любой локальный пользователь без токена
   читает/меняет extensions, general-settings, sip-providers): nftables
   `iifname "lo" meta skuid != 0 tcp dport {80,443} drop` — с loopback к
   API допускается только root. Службы VLANit (heal/doctor) работают от
   root — не затронуты. Правило валидно (nft -c, privileged-проверка).
2. **Зависимость самолечения от bypass:** после закрытия bypass heal
   продолжит работать (root). Основная линия — env-применение DockerCloud
   при каждом старте (п. #10 выше), PATCH — вторая линия.
3. **Пароль открытым текстом:** убран из quadlet-юнита (были видны юнит и
   `podman inspect`) — теперь Podman secret `atc-admin-password`
   (`Secret=...,type=env,target=WEB_ADMIN_PASSWORD`), источник —
   `/etc/vlanit/atc-admin-password` (0600, создаёт установщик; firstboot
   создаёт secret). Проверки агента: atc-secret-exists,
   atc-no-plaintext-in-quadlet. Остаток (пароль в БД АТС CloudInstanceId
   и логах АТС с правами 644) — внутренности образа MikoPBX, зафиксирован
   как известное ограничение upstream (idea #7: SBOM/аудит образа).
