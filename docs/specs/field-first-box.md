# Спека: полевой прогон — первый бокс (issue #42)

Статус: **чеклист готов, прогон не выполнен**. Эпик #36. Зависит:
зеркало (#37, сделано), wiki замены диска (#39), паритет (#40),
миграция данных (#41).

## Корень

Автотесты QEMU зелёные (Т1–Т9, mirror). Продукт не принят, пока нет
одного живого бокса на железе флота: установка с мастера, зеркало на
двух SSD, перенос АТС, выдержка в работе.

## Решение

Один полевой прогон по чеклисту ниже. Результат — в notes релиза и
`docs/testing.md` (ручной раздел; в автотесты не входит). Баги с железа
— отдельные спеки (корень → решение → проверка), не «починить всё».

Отклонено: считать QEMU-mirror заменой полевого прогона — не ловит
KMS/firmware/USB-boot/реальные SSD.

## Чеклист

### A. Подготовка
- [ ] ISO 1.3.2 (или актуальный тег): `sha256sum -c` + GPG
      (`rootfs/etc-vlanit-release.pub`)
- [ ] Железо: 2× SSD ≥64 ГиБ, UEFI, сеть, консоль/HDMI
- [ ] Запись USB (`write-usb.sh` / см. `docs/installation.md`)
- [ ] Сняты данные со старого бокса (если миграция): backup MikoPBX / #41

### B. Установка (интерактивный мастер)
- [ ] Boot USB UEFI, меню GRUB с версией релиза
- [ ] Мастер: hostname, пароль ОС ≥8, пояс, сеть, режим **зеркало**
- [ ] Gauge доходит до конца (не «висит» на развёртывании/импорте)
- [ ] Экран завершения: IP, URL веб-АТС, WG pubkey
- [ ] Reboot с диска, Plymouth/консоль без emergency

### C. После firstboot
- [ ] `vlanit-doctor` — без неожиданных FAIL (`--fix-hints` при FAIL)
- [ ] SSH под админом (root по SSH закрыт)
- [ ] HTTPS веб-АТС, вход с паролем из мастера
- [ ] `podman ps` / `systemctl status mikopbx` — active
- [ ] WireGuard: `wg show`, ключ совпадает с экраном завершения

### D. Зеркало на железе
- [ ] `lvs` — root/data `raid1`; ESP на обоих дисках
- [ ] Изъять диск A → reboot → АТС жива (degraded); doctor WARN ок
- [ ] Вернуть/заменить диск → resync (wiki #39, когда готов)
- [ ] Фото/заметки: серийники дисков, время resync

### E. Паритет и данные (#40 / #41)
- [ ] Сверка критичных настроек со старым боксом (транки, внутренние,
      маршруты) — список в notes
- [ ] Restore данных на новый бокс (если применимо)
- [ ] Контрольный звонок / регистрация SIP-трубки

### F. Выдержка
- [ ] ≥24 ч в работе: doctor --quiet = 0, журналы без критики storage
- [ ] Короткое vs длинное нажатие кнопки питания (игнор / shutdown)

### G. Фиксация
- [ ] Строка/раздел в `docs/testing.md` (дата, ISO, железо, PASS/FAIL)
- [ ] Открытые пункты — честно в notes релиза
- [ ] Issue #42: комментарий с итогами + close при полном PASS

## Проверка (definition of done)

Чеклист A–G пройден или открытые FAIL заведены issues со спеками.
Автотесты не заменяют этот прогон.
